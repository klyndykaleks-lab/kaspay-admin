# Приёмка подключения каталога

Результат каждой проверки записать в журнал: ID, тестовая среда, commit фронта/бэка, роль, ожидаемое и фактическое поведение, доказательство и ответственный. Сейчас все интеграционные проверки ниже ожидают выполнения разработчиками. UI согласован владельцем; код не внедрён.

| ID | Проверка | Ожидаемый результат |
| --- | --- | --- |
| CAT-01 | capabilities на старом API; флаг выключен | Новый модуль не отправляет мутации в старые endpoints; выключенный флаг сохраняет прежний каталог |
| CAT-02 | Создать товар с 4 обязательными полями | Успех; страна BLR по умолчанию, единица pcs, пустой вес null, пустой состав допустим |
| CAT-03 | Пустые/пробельные name, shortName, barcode или отсутствующая категория | Сохранение запрещено, форма и введённые данные сохранены |
| CAT-04 | Вес пустой / 0 / -1 / 1.5; КБЖУ 10.6 / -1 | Пустой вес допустим; 0/-1 отвергаются; дробные значения сохраняются без округления; отрицательные КБЖУ запрещены |
| CAT-05 | Очистить страну и открыть карточку заново | Страна остаётся пустой; mapper и список не падают, товар не исчезает из JOIN |
| CAT-06 | Создать штрихкод с ведущими нулями | Нули сохраняются в API, БД и UI; поиск по фрагменту находит товар |
| CAT-07 | Дубль barcode активного/неактивного товара; свой barcode при редактировании | Дубли запрещены, своя карточка исключена, форма показывает ошибку |
| CAT-08 | Совпадение полного названия при уникальном barcode | Предупреждение, сохранение допустимо |
| CAT-09 | Поиск отдельно по двум названиям, категории, barcode с разным регистром и пробелами | Полный серверный поиск через ИЛИ до пагинации, совпадения на других страницах не теряются |
| CAT-10 | Фильтры + поиск + 10/20/50 строк; удаление последней строки последней страницы | Корректные totalItems/totalPages и номер страницы; сброс на первую при смене условий |
| CAT-11 | Отключить, отменить отключение, включить; редактировать неактивный товар | Подтверждение и отмена работают; состояние сохраняется после reload; PUT не активирует автоматически |
| CAT-12 | Фото 150×150 / 151×150 / 150×151 / больше 1MB / неверный формат | 150×150 разрешено; остальные отклонены в UI и сервером; обход UI не обходит проверку |
| CAT-13 | Заменить/удалить фото и нажать Отмена/крестик/Escape | Ни одного запроса удаления/замены; старое фото остаётся в БД/хранилище |
| CAT-14 | Закрыть карточку во время чтения файла и открыть другую | Поздний результат не попадает в другой черновик |
| CAT-15 | Сбой сохранения, в том числе ошибки хранилища/commit | Форма открыта, черновик сохранён, старая карточка и фото не изменились |
| CAT-16 | Повтор POST после timeout; двойной клик; конфликт version | Один товар при том же ключе; повторный клик недоступен; устаревшая версия получает 409 без перезаписи |
| CAT-17 | Создать категорию без описания | Активна по умолчанию; в форме нет Switch; состояние меняется в списке |
| CAT-18 | Дубликаты категории точные, разный регистр, пробелы; неактивный дубль; переименование | Немедленная ошибка и блокировка формы; сервер 409; своя категория допустима |
| CAT-19 | Поиск категорий по name/description + active/inactive/all | Сочетание условий корректно; только 3 столбца, Switch в действиях |
| CAT-20 | Отключить категорию с товарами, назначить новому товару | Существующие связи и активность товаров сохраняются; новое назначение запрещено |
| CAT-21 | Переименовать категорию; удалить используемую/с дочерними | Название видно у товаров и в поиске; удаление блокируется, данные не теряются |
| CAT-22 | businessUser / deviceServicer; чужой tenant; прямой запрос без UI | Права чтения/записи и tenant проверяются сервером, чужие объекты не раскрываются |
| CAT-23 | Два одновременных создания с одинаковым barcode или нормализованной категорией | Одна запись, второй запрос 409; уникальность обеспечена БД |
| CAT-24 | Миграция существующих данных | Без потери товаров/фото/категорий; единица pcs; дубли требуют отдельного решения; иерархия сохранена |
| CAT-25 | Регрессия матриц, прайсов, склада и терминального каталога | ID и связи сохранены; эти разделы не требуют ручного восстановления |

Проверить отдельно с менеджером продукта: как отключённые товары и категории должны влиять на уже настроенные матрицы/прайсы терминала; полноту поддержки единиц МЛ/ГР в операциях остатков и продаж. Эти межраздельные решения не расширяются автоматически из переключателя в прототипе.
